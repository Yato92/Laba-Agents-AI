# 🎵 Vein's Notes — Умное управление заметками

> **Vein's Notes** — это полнофункциональное SPA-приложение для управления заметками с современным тёмным дизайном, календарём, системой контактов и полной поддержкой авторизации.

---

## 📋 О проекте

**Vein's Notes** — это проект для лабораторной работы, представляющий собой полноценную систему управления заметками с клиент-серверной архитектурой. Приложение позволяет создавать, редактировать и удалять заметки, отслеживать дедлайны, управлять контактами, а также наглядно видеть распределение задач на календаре.

### 🚀 Функциональные возможности

| Функция | Описание |
|---------|----------|
| 🔐 **Авторизация** | Регистрация, вход, восстановление пароля через email-подтверждение |
| 📝 **Заметки** | CRUD-операции с заголовком, описанием, датой, дедлайном и приоритетом |
| 📅 **Календарь** | Визуальное отображение заметок по дням с цветовой индикацией |
| ⭐ **Важные задачи** | Отдельный виджет для задач с высоким и критическим приоритетом |
| 👥 **Контакты** | Управление контактами с симуляцией чата и звонков |
| 👤 **Профиль** | Настройка профиля, аватара, темы и языка |
| 🌙 **Тёмная/светлая тема** | Переключение между темами оформления |
| 🌐 **Локализация** | Поддержка русского и английского языков |
| 🤖 **VK Бот** | Уведомления о дедлайнах, управление заметками через ВКонтакте |
| 🧠 **AI-агент (Ollama)** | Текстовый ассистент, создание/удаление заметок естественным языком, умные напоминания |

## 🌟 Ключевые особенности реализации

### 1. Полная аутентификация
- Регистрация с подтверждением email (6-значный код)
- Вход по email/паролю
- Восстановление пароля через код на почту
- Интеграция с EmailJS для реальной отправки писем

### 2. Умный календарь
- Прокрутка по месяцам
- Цветовые индикаторы для заметок, дедлайнов и важных задач
- Клик по дате показывает все связанные заметки
- Быстрое добавление заметки на выбранную дату

### 3. Дизайн-система
- Полностью кастомный CSS с CSS-переменными
- Тёмная и светлая темы
- Анимации, градиенты, тени
- Адаптивная сетка рабочего пространства

### 4. Локализация (i18n)
- Русский и английский языки
- Переключение без перезагрузки страницы
- Полный перевод всех элементов интерфейса

### 5. Серверная часть
- REST API с JSON-ответами
- SQLite для лёгкого развёртывания
- bcrypt для безопасного хранения паролей
- Раздача статических файлов одним сервером

## 🤖 Интеграция с VK и AI-агент

### 📱 VK Бот (уведомления и напоминания)
- Бот работает в социальной сети ВКонтакте и получает сообщения от пользователя
- Позволяет отправлять напоминания о предстоящих дедлайнах заметок прямо в VK
- При создании или приближении важной заметки (высокий/критический приоритет) бот отправляет уведомление
- Реализована двусторонняя связь: можно запросить список всех заметок через VK-бота
- Технически: Node.js-сервер слушает Callback API VK, хранит соответствие `vk_user_id` ↔ `user_id` приложения

### 🧠 AI-агент (Ollama + Llama 3.1:8b)
Встроенный в интерфейс сайта интеллектуальный помощник на базе локальной LLM:

| Функция | Описание |
|---------|----------|
| 💬 Чат-ассистент | Плавающее окно чата на всех страницах приложения |
| ✨ Создание заметок голосом или текстом | "Напомни купить продукты завтра в 18:00" → автоматически создаётся заметка |
| 🗑️ Удаление заметок | "Удали все заметки про встречу" → AI понимает контекст и удаляет нужные |
| ⏰ Умные напоминания | Агент сам предлагает установить напоминание, если видит в сообщении временной маркер |
| ❓ Ответы на вопросы о функционале | "Как поменять тему?" → AI объясняет шаги по интерфейсу |
| 📅 Интеграция с календарём | Может показать заметки на завтра или на текущую неделю |

**Техническая реализация:**
- Локальный сервер **Ollama** с моделью `llama3.1:8b` (запускается отдельно)
- Backend (Express) проксирует запросы от фронтенда к Ollama API, добавляя системный промпт: *"Ты — AI-помощник Vein's Notes. Управляй заметками через вызовы функций. Доступные действия: create_note(title, description, deadline, priority), delete_note(id), get_notes_by_date(date), get_important_notes. Если пользователь просит что-то из этого — верни JSON с action и параметрами."*
- Фронтенд (app.js) обрабатывает ответы AI: если в ответе присутствует JSON с action, выполняет соответствующую операцию с заметками (через localStorage/сервер) и подтверждает выполнение
- Все диалоги сохраняются в истории чата (отдельная вкладка в боковой панели)

### Архитектура взаимодействия с AI-агентом

```
Пользователь → [Чат-виджет] → POST /api/ai/chat → Express → Ollama (llama3.1:8b)
                                    ↓
                    Ответ (текст + возможно JSON-команда)
                                    ↓
     Фронтенд: если есть action → выполняет CRUD → обновляет UI → отвечает пользователю
```

## 🧠 Что было сделано

1. **Создана архитектура SPA** — одностраничное приложение с навигацией через `display: none/block` (все страницы в одном HTML).
2. **Разработана дизайн-система** — полный набор CSS-переменных, компонентов (карточки, модалки, кнопки, календарь), тёмная/светлая темы.
3. **Реализована клиентская логика** — модульная JS-архитектура с CRUD для заметок и контактов, календарём, аутентификацией, чатом, настройками.
4. **Написан сервер** — Express с SQLite, bcrypt, REST API для регистрации.
5. **Локализация** — словарь для русского и английского языков с динамическим переключением.
6. **Оформлен `.gitignore`** — исключены `node_modules/`, `database.db`, `.env`.
7. **Интегрированы VK бот и AI-агент** — создан бот для уведомлений и управления заметками через ВКонтакте, а также локальный AI-помощник (Ollama + llama3.1:8b) с функцией вызова CRUD-операций через естественный язык.
