# 🎵 Vein's Notes — Умное управление заметками (AI Agent)

> **Vein's Notes** — SPA-приложение для управления заметками с локальным AI-ассистентом на базе **Ollama (llama3.1:8b)**, интеграцией с VK, календарём и тёмной темой.

---

## 📋 О проекте

**Vein's Notes** — проект для лабораторной работы по курсу «Агенты ИИ». Приложение позволяет создавать заметки, отслеживать дедлайны, управлять задачами, общаться с AI-ассистентом, который понимает естественный язык и может создавать заметки, отвечать на вопросы, напоминать о дедлайнах.

**Главная особенность:** AI работает **полностью локально** через Ollama — никаких облачных API, всё на вашем компьютере.

---

## 🚀 Как запустить локально (с AI)

### Шаг 1: Установить Ollama

Скачайте с официального сайта: **https://ollama.ai/download**

- **Windows:** установщик `.exe`
- **macOS:** `.dmg`
- **Linux:** `curl -fsSL https://ollama.ai/install.sh | sh`

После установки Ollama автоматически запускается как фоновый сервис.

### Шаг 2: Загрузить модель

Откройте **новый терминал** (PowerShell / cmd / bash) и выполните:

```bash
# Скачать модель Llama 3.1 (8B параметров, ~4.7 ГБ)
ollama pull llama3.1:8b

# Или более лёгкую версию (3B, ~2 ГБ) — быстрее
ollama pull llama3.2:3b
```

> **💡 Для слабых ПК:** `ollama pull phi3:mini` (~2.3 ГБ), `ollama pull tinyllama` (~700 МБ)

### Шаг 3: Проверить, что Ollama работает

```bash
curl http://localhost:11434/api/tags
```

Должен вернуться JSON со списком моделей (например, `{"models":[{"name":"llama3.1:8b:latest",...}]}`).

> **⚠️ Если Ollama не отвечает:** откройте терминал и запустите `ollama serve` вручную.

### Шаг 4: Клонировать проект и установить зависимости

```bash
git clone <url-репозитория>
cd "Viennese Notes website"
npm install
```

### Шаг 5: Настроить `.env` (опционально)

Файл `.env` уже создан. Если нужно изменить модель или порт:

```env
# Ollama
OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=llama3.1:8b    # или llama3.2:3b, phi3:mini

# Сервер
PORT=3000

# VK (опционально — для уведомлений в ВК)
VK_TOKEN=ваш_токен
```

### Шаг 6: Запустить сервер

```bash
node server.js
```

Вы увидите:
```
============================================
  🚀 Vein's Notes Server запущен!
  📍 http://localhost:3000
  🤖 AI: POST http://localhost:3000/api/ollama
============================================
```

### Шаг 7: Открыть сайт

Перейдите в браузере: **http://localhost:3000**

1. Зарегистрируйтесь (email + пароль)
2. Нажмите кнопку **AI 🤖** в правом нижнем углу
3. Напишите сообщение:
   - *"Привет!"* — простой ответ
   - *"Создай заметку купить продукты завтра"* — создаст заметку с дедлайном
   - *"Какие у меня дедлайны?"*
   - *"Напомни о встрече в пятницу"*
   - *"Удали заметку про встречу"*

## 🤖 Как работает AI-агент

AI-ассистент — это **локальная LLM (llama3.1:8b)**, запущенная через Ollama. У неё специальный **системный промпт**, который настраивает AI на работу именно с заметками и дедлайнами:

- Понимает команды на естественном языке
- Может **создавать заметки** через команду `#CREATE_NOTE {title, description, deadline, importance}`
- Отвечает кратко (2-4 предложения), с эмодзи
- Помнит контекст ваших заметок и дедлайнов

**Схема работы:**
```
Пользователь → [Чат-виджет] → POST /api/ollama → Express → Ollama (llama3.1:8b)
                                      ↓
                      Ответ + возможно #CREATE_NOTE
                                      ↓
       Фронтенд: создаёт заметку → обновляет календарь/список
```

## 🏗️ Архитектура

```
veins-notes/
├── index.html       ← Главная SPA-страница (весь UI)
├── style.css        ← Дизайн-система (тёмная/светлая тема)
├── app.js           ← Клиентская логика (авторизация, заметки, AI-чат)
├── server.js        ← Express-сервер + API + прокси к Ollama
├── package.json     ← Зависимости
├── vercel.json      ← Конфигурация деплоя на Vercel
├── api/

└── .env             ← Настройки (Ollama, VK)
```

### Два режима работы

| Режим | AI | Как запустить |
|-------|----|---------------|
| **Локально** | ✅ Работает | `ollama pull llama3.1:8b` + `node server.js` |
| **На Vercel** | ❌ Недоступен | `vercel --prod` (показывает инструкцию в чате) |

## 📝 Команды AI-чата

| Что написать | Результат |
|-------------|-----------|
| `Привет` | AI поздоровается |
| `Создай заметку [текст]` | Создаёт заметку |
| `мои заметки` | Показывает список |
| `дедлайны` | Сортирует по срокам |
| `удали заметку [название]` | Удаляет заметку |
| `что у меня завтра` | Показывает задачи на завтра |
| Любой другой вопрос | AI отвечает как ассистент |

## 🔄 Запуск на Vercel (без AI)

